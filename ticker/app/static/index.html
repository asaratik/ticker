        Fitbit

        Garmin Connect

        Signs in the way Garmin's own app does, through the community garminconnect library: automatic, but unofficial, and Garmin has broken it before. Your password is used once and never stored. If it stops working, import Garmin's data export below — nothing already recorded is lost.

        Import a file · Apple Health, Garmin

        Apple Health: on your iPhone, Health → your picture → Export All Health Data, and copy export.zip here. Garmin: request your data and use the zip Garmin emails you, or a .fit file from the watch. Importing a newer file later adds only what's new.

        A chest strap or a Garmin watch? Turn it on under Live heart rate.
